## Reporting a Vulnerability

If you discover a security vulnerability (such as buffer overflows in the Linux daemon serial protocol parser, permission escalation risks in `99-fancontrol.rules`, or thermal watchdog bypass conditions), please report it responsibly:

1. **Do not disclose the issue publicly** on GitHub issues, forums, or public chat.
2. Please open a private Security Advisory on GitHub or contact the maintainer directly.
3. Include detailed steps to reproduce the vulnerability, including a proof-of-concept (PoC) if available.
4. We will acknowledge receipt of your report within 48 hours and work on a patch promptly.

Thank you for helping keep our systems and PC hardware safe!
